# Abstract Asset Sources

> [!abstract] Approved discovery catalog
> Use this list when DAOVOS needs abstract SVGs, patterns, imagery, or visual data structures. An entry is a discovery source—not automatic permission to ship an asset. Verify the license for the exact asset, save a local production copy, and record its source URL before use.

## Interactive generators and SVG tools

- [Haikei](https://haikei.app/) — waves, blobs, stacked steps, layered peaks, low-poly meshes; SVG/PNG export.
- [Blobs](https://blobs.app/) — controllable organic SVG forms.
- [MeshGradient.in](https://meshgradient.in/) and [CSS Hero Mesher](https://csshero.org/mesher/) — mesh backgrounds exported as CSS/SVG.
- [Get Waves](https://getwaves.io/) and [ShapeDivider](https://shapedivider.app/) — SVG waves and section dividers.
- [Fffuel](https://fffuel.co/) — grain, halftone, wavy-line, vortex, perspective, and mesh generators. See the [Fffuel license](https://www.fffuel.co/license/) before use.

## Abstract systems and chart geometry

- [Bklit](https://bklit.com/) — chart and data-visualization structures. Prefer its open-source chart components; the chart library is documented in the [Bklit UI repository](https://github.com/bklit/bklit-ui). Do not copy proprietary Bklit Studio artwork.

## 3D, chrome, glass, and material assets

- [Spline](https://spline.design/) — interactive 3D scenes and transparent exports. Use only after a performance review; the site does not need 3D by default.
- [Drawer](https://drawer.design/) and [LS Graphics](https://www.ls.graphics/) — glass, holographic, chrome, and high-resolution abstract assets.
- [Pixelbuddha](https://pixelbuddha.net/) — free and premium holographic, glass, plastic, and iridescent packs.

## Figma Community

- Blob / Smooth Curves generators.
- Mesh Gradient and Noise / Texture plugins.
- Useful community searches: `3D Chrome Abstract`, `Glassmorphism UI Kit`, `Y2K Vectors`, `Memphis Shapes`.

## Vector and design marketplaces

- [Freepik](https://www.freepik.com/) and [Vecteezy](https://www.vecteezy.com/) — geometric vectors, blobs, and fluid backgrounds; confirm attribution and commercial terms per asset.
- [Envato Elements](https://elements.envato.com/) and [Creative Market](https://creativemarket.com/) — commercial-grade render, liquid, acid-graphic, and abstract bundles; preserve purchase/license records.

## Photography and rendered imagery

- [Unsplash](https://unsplash.com/) and [Pexels](https://pexels.com/) — search `abstract 3D`, `fluid gradient`, `minimal render`, architecture, concrete, glass, infrastructure, or interface systems.

## DAOVOS usage rules

1. Keep assets within the canonical bone-white / near-black / graphite palette; monochrome treatment is the default.
2. GSAP owns runtime motion. Do not retain a source site's CSS keyframes, Framer Motion, or proprietary animation runtime.
3. Prefer local SVG/image files over remote hotlinks. Optimize, name, and caption every shipped asset.
4. No gradients, glassmorphism, chrome, or 3D merely because a source offers them; use only when the active art direction explicitly calls for them.
5. Record the exact source page, author when available, license, and any adaptation in the implementation session note.
6. Keep visuals spacious and materially distinct; do not repeat one pattern with superficial variations.

# Buttermax Clone

A pixel-accurate, buttery-smooth digital studio portfolio clone of [buttermax.net](https://buttermax.net), built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## 🧈 Features

- **Kinetic Typography & Editorial Hero**: Signature Buttermax animated headlines (*"The Gold Standard in Buttery Smooth Digital Production"*).
- **Curated Projects Showcase**: Complete interactive portfolio featuring all 9 case studies:
  - **Spotify 2023 Wrapped**
  - **Patreon.com Redesign**
  - **GDK.com (German Doner Kebab WebGL)**
  - **Spotify Rap UK (Day 1 Club)**
  - **Dreamwave 2.0 (WebXR Platform)**
  - **Chrome Pit Crew (McLaren F1 Minigame)**
  - **Reliable Robotics (Aviation 3D Storytelling)**
  - **The Dreamkeeper (AI & Stable Diffusion)**
  - **Google Search Through Time**
- **Interactive Case Study Modals**: Deep-dive project drawers with client info, year, disciplines, and visual galleries.
- **Custom Interactive Cursor**: Buttery yellow magnetic cursor with context-aware hover states.
- **Studio & Capabilities**: Interactive "Who We Are" manifesto, service pillars, and production capabilities.
- **Inquiry Drawer**: Smooth contact modal for project inquiries.
- **Responsive & Dark-Themed**: Designed for desktop, tablet, and mobile with custom scrollbars and yellow glowing accents.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3005](http://localhost:3005) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
